# Gourmet Gastronomer

A long-lived food encyclopedia, skills library, and San Francisco / Bay Area food atlas.

The corpus lives in `content/`. The site is a static Astro 7 build.

## Commands

```sh
npm install
npm run dev
npm run validate
npm test
npm run lint
npm run check
npm run build
npm run report:sources
npm run report:graph
npm run suggest:links
```
